\section*{Problem 1}
Find the projection of a given point $\vx\in \RR^n$ onto the set $X$. Justify your solution. For Questions 1 and 2, sketch the set $X$ and plot where the projected point is on $X$.

\begin{enumerate}
\item  $X = \{\vx\in \RR^2: x_1 \ge 0, x_2 \ge0, 2x_1 + x_2 \le 2\}$; $\vx = [1; 2]$

\item \textbf{(Only for 4820 students:)} $X = \{\vx\in \RR^2: x_1 <= 0, x_1^2 + x_2^2 \le 1\}$; $\vx = [-2; 2]$

\item \textbf{(Only for 6610 students:)} Derive the projection formula for $X = \{\vx\in \RR^n: \vA\vx = \vb\}$ and any $\vx\in\RR^n$, where $\vA \in \RR^{m\times n}$ with $m< n$ has a full-row rank, and $\vb\in \RR^m$ is in the range of $\vA$.

\end{enumerate}

 Derive the formula of $\prox_g$ at any point $\vx\in \RR^n$.

\section*{Problem 3} 

Consider the unconstrained quadratic minimization problem:
\begin{equation}\label{eq:un-quad-min}\tag{QuadMin}
\Min_\vx f(\vx) = \frac{1}{2}\vx^\top \vA \vx - \vb^\top \vx
\end{equation}
where $\vA\in\RR^{n\times n}$ is a symmetric positive definite matrix, and $\vb\in\RR^n$.

Write a solver for \eqref{eq:un-quad-min} by the DFP method. Use the instructor's provided file \verb|quadMin_DFP.m| to write a Matlab function \verb|quadMin_DFP| with input $\vA$, $\vb$, initial vector $\vx0$, and tolerance \verb|tol|, and with stopping condition $\|\nabla f(\vx^k)\| \le \text{tol}$. Also test your function by running the provided test file \verb|test_DFP.m| and compare to the instructor's function. Print your code and the results you get, and print the figures you get.
